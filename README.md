# basics-social-videos

Public video files for the Basics Instagram accounts, served by GitHub Pages so Instagram can fetch them.
The schedules, captions and covers live in alexgateley/icubasics-social; a post folder there holds
`video_url.txt` pointing at a file here (that repo is near GitHub's 5 GB guideline).

Layout: `<brand>/<folder>.mp4` (brands: er, rt, ekg, np, pharm, lab).
